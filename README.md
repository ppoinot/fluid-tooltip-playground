# Fluid Tooltip Playground

A working, tweakable copy of the fluid sidebar tooltip originally posted by
**[Anthony Lorenzo](https://x.com/Anthony99_s)** on X:

> **[https://x.com/Anthony99_s/status/2114869597577023821](https://x.com/Anthony99_s/status/2114869597577023821)**

All credit for the original design, animation, and the underlying spring
concept goes to Anthony Lorenzo. This repository only exposes the knobs
(stiffness, damping, label roll, blur, open delay, skip-delay window) so the
spring physics behind the tooltip can be explored interactively, and recreates
the equivalent in Framer Motion code for reference.

## Live demo

**[ppoinot.github.io/fluid-tooltip-playground](https://ppoinot.github.io/fluid-tooltip-playground/)**

Hover the icons in the sidebar, press **Replay** to watch the scripted demo,
or drag the sliders to see how each parameter changes the feel of the spring.
